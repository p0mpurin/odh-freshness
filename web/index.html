Method

How it works

Every hour this page asks the Mobility API v2 for every station type, every station marked active, and the latest value of each of its data types. A station is judged by its newest value.

    According to the Open Data Hub documentation, a station is set to inactive after 24 hours without data. The silent and dead stations here are still marked active, so either their feed is broken or the flag was never updated.

    Raw results: data.json (this page) · report.json (every station).
